# 연구의 이야기

연구자가 청중을 기준으로 학술 발표를 설계하는 웹앱입니다.

## 실행

```bash
npm install
npm run dev
```

표시되는 로컬 주소를 브라우저에서 여세요. 배포용 빌드는 `npm run build`입니다.

## 사용 흐름

1. 연구 내용과 청중, 발표 시간, 핵심 메시지를 입력합니다.
2. 가상 청중의 질문에 하나씩 답하고, 충분하다고 판단하면 흐름 초안으로 넘어갑니다.
3. 대화 내용이 일부 반영된 발표 흐름 초안을 직접 수정하거나, 오른쪽 도우미의 변경안을 검토한 뒤 적용합니다.
4. 구간별 주장, 근거, 시각 자료, 예상 질문을 적습니다.
5. 의도한 메시지와 스토리보드에 적힌 주장을 비교해 수정합니다.

프로젝트는 사용 중인 브라우저의 로컬 저장소에 저장됩니다. 다른 기기에서 이어서 작업하려면 **프로젝트 내보내기**로 JSON 파일을 받은 뒤 다른 기기에서 **가져오기**를 사용하세요. 자동 동기화는 제공하지 않습니다.

## OpenAI 연결

Vercel 프로젝트의 **Settings → Environment Variables**에 다음 값을 등록합니다.

- `OPENAI_API_KEY`: OpenAI API 키. 브라우저 코드나 GitHub에 넣지 마세요.
- `AI_ACCESS_CODE`: 테스트 참여자에게만 알려줄 긴 임의의 사용 코드. 공개 사이트의 AI 호출을 제한합니다.
- `OPENAI_MODEL` (선택): 사용할 모델. 기본값은 `gpt-4o-mini`입니다.

두 필수 값을 Production 환경에 등록한 후 Vercel에서 **Redeploy**해야 적용됩니다. 사이트 상단에 사용 코드를 입력하면 AI 질문, 흐름 초안, 흐름 변경 제안, 이해 점검을 사용할 수 있습니다. 사용 코드는 해당 탭의 세션 저장소에만 보관합니다. 연구 내용과 대화는 AI 요청 시 OpenAI API로 전송됩니다. 이 앱은 AI 응답을 자동으로 사실 검증하지 않으므로 주장과 근거를 원자료와 대조해 주세요.

키와 사용 코드가 설정되지 않았거나, 로컬에서 `npm run dev`로 실행하면 규칙 기반 데모가 동작합니다. 데모의 이해 점검은 작성한 스토리보드의 입력 상태를 확인하며 실제 청중 반응을 예측하지 않습니다. 연구 자료는 붙여 넣거나 `.txt`/`.md` 파일로 불러올 수 있습니다. PDF 자동 분석은 아직 지원하지 않습니다.
