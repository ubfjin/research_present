# 연구의 이야기

연구자가 청중을 기준으로 학술 발표를 설계하는 웹앱입니다.

## 실행

```bash
npm install
npm run dev
```

표시되는 로컬 주소를 브라우저에서 여세요. 배포용 빌드는 `npm run build`입니다.

## 사용 흐름

1. 연구 내용과 청중, 발표 시간, 핵심 메시지를 입력합니다.
2. 가상 청중의 핵심 질문 3개에 답합니다.
3. 발표 흐름의 순서와 시간을 조정합니다.
4. 구간별 주장, 근거, 시각 자료, 예상 질문을 적습니다.
5. 의도한 메시지와 스토리보드에 적힌 주장을 비교해 수정합니다.

프로젝트는 사용 중인 브라우저의 로컬 저장소에 저장됩니다. 다른 기기에서 이어서 작업하려면 **프로젝트 내보내기**로 JSON 파일을 받은 뒤 다른 기기에서 **가져오기**를 사용하세요. 자동 동기화는 제공하지 않습니다.

현재는 AI API가 연결되지 않은 데모입니다. 청중 질문은 규칙 기반 예시이며, 이해 점검은 작성한 스토리보드의 입력 상태를 확인합니다. 실제 청중의 반응이나 독립적인 AI 재설명을 예측하지 않습니다. 연구 자료는 붙여 넣거나 `.txt`/`.md` 파일로 불러올 수 있습니다. PDF 자동 분석은 아직 지원하지 않습니다.
